# Dataset

`wolfhacks_2026_student_outcomes.xlsx` — official WolfHacks 2026 Data Science & AI track dataset.
Sheets: README, Student Data (800 rows x 19 columns), Data Dictionary.
All records are synthetic; no real students are represented. `at_risk = 1` means a final D/F.
The file has no timestamps; the activity timeline in the dashboard is generated (see docs/TIGER_DATA.md).
